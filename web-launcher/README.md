# Moddest Web Launcher

Download [Open-Moddest.html](https://github.com/Huluaccount2/Moddest-Portable/raw/refs/heads/main/web-launcher/Open-Moddest.html) and open it with Google Chrome. On a Mac, use Finder's Open With > Google Chrome if HTML files normally open in Safari. No Terminal, Node.js or executable installer is needed.

The file opens https://moddest.uk/niche in the same tab. On that page, choose Install Moddest beside your account if Chrome offers it. Installation opens Moddest in its own app window; availability depends on browser and device policy.

This is a website shortcut, not an offline copy or a signed macOS application. It cannot install the web app before reaching the website, bypass a blocked address, or override school management policies. Online accounts and features continue using the existing Moddest services.

The separate Moddest Portable packages are different: their full online mode uses a local server and requires permission to run it.
